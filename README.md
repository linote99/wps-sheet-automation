# WPS 表格多源汇总处理器

面向 **Windows 11 + WPS 表格 + 无宏 XLSX** 的 GUI 工具。主结果写入模板临时副本，不覆盖模板或源文件。

## 本次更新（v18，配置 v13）

- 新增“设置”窗口，包含秘钥管理、使用说明和配置管理三个页面。
- 秘钥管理显示本机机器码、授权状态及当前秘钥到期日期；更新秘钥前校验签名、产品、机器码和有效期，只有校验通过才替换现有秘钥。
- 使用说明集中介绍模板与多源数据、目标表、结果映射/后映射、公式及区域处理、输出、工作流和安全边界。
- 配置管理支持导出当前界面配置、导出选中的命名配置及删除单个命名配置；删除前明确确认，不影响当前界面内容或其他配置档。
- 保持结果映射与后映射的独立性、顺序和原有配置格式；秘钥仍由独立本机文件保存，主程序和 main-only 发布包不包含签名私钥。

## v17 修订版（配置 v13）

- 新增“公式填充”规则：可以输入自定义公式，或指定同一工作表中的公式单元格作为种子；由 WPS 将公式按相对引用填满所选区域。公式由 WPS 解析和计算，可使用当前 WPS 版本支持的函数；外部工作簿引用及部分外部访问函数仍由既有安全检查拦截。
- 公式填充既可用于源文件，也可用于模板。源侧在 WPS 临时副本中先执行、重算，再读取处理结果；目标侧在模板的输出副本中执行。源文件原件不会被修改。
- 公式填充会替换所选范围内原有的值或公式；可在不同规则间分别指定范围。后续文本分列、筛选、去重、格式转换不能覆盖公式区域，以避免丢失公式。
- 区域筛选支持单填 `A` 表示 A 列、`a1` 表示 A1 单元格；`A1` 表示整张工作表。整表/整行/整列规则按 WPS `UsedRange` 裁剪后执行。
- 恢复可选的“结果映射”：可按每个目标表将公式列已计算结果按值或文本写入指定目标列；不配置时不会强制写回。原有“后映射”独立保留，可复制任意源/目标区域，二者按“结果映射→后映射”顺序执行。
- 区域 XLSX 始终输出；勾选图片时额外输出 PNG。
- 模板可单独处理，无需添加源文件。无源目标表会保留模板已有内容；仍可执行模板范围规则、公式填充、映射、区域输出和文本预览。
- 可勾选保留编辑后的源副本；副本写入输出目录并以“原文件名_已编辑.xlsx”命名，重名时追加编号，不覆盖已有文件。

## 数据与模板设置

可配置多个目标工作表。每个目标表的源文件列表可以留空，也可以按顺序添加多份源文件；源工作表名留空时使用源文件第一张表。多份源数据依次追加。复制列范围只在关联源文件时必填，结束行留空时按所有已使用列寻找首个整行空白边界，否则使用最后非空行。

关联源文件时，程序先在临时副本中执行该源文件匹配到的规则，再从处理后的副本读取数据、编辑模板。模板独立处理时，主数据清理、复制和按数据行数自动填充模板公式会跳过；配置的模板规则（包括自定义公式填充）仍可执行。

## 处理范围与工作流

默认工作流先执行源文件规则处理，再清理/编辑模板；随后执行前映射、数据复制、模板自动公式填充、首次重算、可选结果映射、可选后映射、自定义公式填充、文本分列/区域筛选/去重/格式转换、最终重算保存，最后输出区域文件和文本预览。工作流页会检查依赖顺序：结果映射须在首次重算后、后映射前；自定义公式填充位于后映射之后，并早于其他区域数据操作。结果映射与后映射均可独立留空。

每条区域规则可以选择“源文件”或“目标工作簿”，并指定工作表和范围。常用范围写法：`A1` 表示整张工作表，`D1` 表示整列 D，`A5` 表示第 5 行，`B3,B3` 表示单格，两个端点如 `D8,B3` 表示自动规范化的矩形。整表、整行、整列按 WPS `UsedRange` 裁剪；区域筛选另支持单填 `A` 表示 A 列、单填小写 `a1` 表示 A1 单格。每条处理规则最多处理 500,000 个单元格。

**结果映射**在目标表配置中单独设置：`result_col` 必须位于该表的 `formula_range`，`target_col` 必须在公式范围外；`write_as` 可设为 `value` 或 `text`。它仅将本轮公式结果行写入目标列。**后映射**仍是模板内部任意源/目标区域间的值复制规则，且可不配置；它在首次完整重算及结果映射之后执行。目标表后映射使用整列别名时，只映射从 `jobs[].start_row` 到本轮数据末行的行，不覆盖前一行公式模板；例如 `start_row` 为 3 时，保留第 2 行公式模板。两个功能可同时配置，也可分别留空。

- **公式填充**：模式一填写以 `=` 开头的自定义公式，例如 `=SUM(A1:B1)`；模式二填写同一工作表中的来源单元格（如 `B2`）。程序读取公式的 WPS `FormulaR1C1` 表示，再写入整个选区，让 WPS 按相对引用生成每格公式。公式填充会覆盖选区既有内容；源侧只作用于临时副本，模板侧只作用于结果副本。
- **区域筛选**：支持等于、不等于、包含、不包含、开头为、结尾为、大于/大于等于/小于/小于等于、为空和不为空；文本匹配不区分大小写，数字条件支持数值比较。可设置表头。筛选只压缩所选区域，不删除整张工作表的物理行；需要保持整条记录对齐时，应将相关列全部包含在区域内。
- **去重**：按区域整行或区域内指定的一列/多列判重，稳定保留第一次出现的记录；有表头时保留首行。只压缩所选区域，不删除工作表物理行。
- **文本分列**：从明确指定的单列按分隔符拆分，逐列设置文本、数字或日期类型和输出起始列；目标区域必须为空，避免覆盖现有数据。
- **格式转换**：将指定范围转换为文本、数字或日期，并设置相应数字格式。日期支持日期单元格、Excel 日期序号及常见日期文本格式。

源文件侧规则先于模板规则执行；启用“保留源文件处理结果”后，处理过的副本才会另存到输出目录。区域处理发现其他规则试图覆盖公式区域时会停止并给出提示。

## 区域 XLSX、PNG 与文本预览

在“区域 XLSX 输出”页添加模板工作表及范围。每个区域 XLSX 保留模板相应单元格的填充色、字体颜色、数字格式/显示位数、边框和对齐等样式。图片复选框只控制是否额外导出 PNG，不影响 XLSX；区域文件输出不会覆盖现有文件。文本预览/复制可配置多个工作表范围；完成保存后界面显示区域内容，并可按行换行、列间 Tab 的方式复制。

## 配置格式

配置版本为 **13**。每个 `jobs[]` 项目可包含一个可选 `mappings` 数组，例如 `[{"result_col":"EJ","target_col":"DG","write_as":"value"}]`；留空数组表示不使用结果映射。`post_mappings` 仍独立保存。前映射、后映射、区域 XLSX、可选 PNG、可选保留源副本及区域公式填充规则均会保存。模板独立编辑时，`jobs[].sources` 可以为空，且 `copy_start_col`、`copy_end_col` 均无需填写。公式规则示例：

```json
{
  "config_version": 13,
  "workflow": [
    "source_preprocess", "template_cleanup", "pre_mapping", "source_copy",
    "formula_fill", "formula_recalc", "result_mapping", "post_mapping", "CustomFormula",
    "TextToColumns", "RegionFilter", "Deduplicate", "FormatConvert",
    "final_recalc_save", "image_output", "text_output"
  ],
  "CustomFormula": {
    "enabled": true,
    "rules": [{
      "scope": "target", "sheet": "汇总", "range": "C2:C100",
      "formula_mode": "custom", "formula": "=SUM(A2:B2)", "seed_cell": ""
    }]
  }
}
```

将 `formula_mode` 设为 `cell` 时，程序从同一工作表的 `seed_cell`（例如 `B2`）读取公式并填充；`formula` 字段此时留空。旧配置会自动迁移。默认配置见 `default_config.json`。

## Windows 构建与验证

main-only 包附带 `install_and_build.bat` 和 Inno Setup 脚本。Windows 上需要 Python 3.10+、WPS 表格和可选的 Inno Setup 6；运行构建脚本会执行语法检查、自检与静态回归并生成程序目录和 v18 安装器。当前代码已在 Linux 上完成静态及合成工作簿测试；WPS COM 的实际公式函数解析、Windows GUI 与 EXE 仍需在目标 Windows 环境验收。
