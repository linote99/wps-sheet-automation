# WPS 表格多源汇总处理器

面向 **Windows 11 + WPS 表格 + 无宏 XLSX** 的 GUI 工具。主结果始终写入模板临时副本，不覆盖模板或源文件。

## 本次更新（v16，配置 v11）

- 区域筛选支持单填 `A` 表示 A 列、`a1` 表示 A1 单元格；`A1` 表示整张工作表。整表/整行/整列规则按 WPS `UsedRange` 裁剪后执行，不按 Excel 最大行列数占用处理上限。
- 公式结果列映射已取消；模板内前映射、后映射继续保留。
- 区域 XLSX 输出功能恢复：配置的区域始终另存为 XLSX；勾选“额外输出区域 PNG”时再输出 PNG，PNG 导出失败不会删除已生成的区域 XLSX。
- 模板现在可单独处理，无需添加源文件。没有源文件的目标表会保留模板现有内容，不执行主数据清理、复制或公式填充；仍可执行模板范围规则和前/后映射，也不要求填写源数据复制列范围。
- 配置了源文件时，源范围规则会**先**在 WPS 临时副本中执行，再从处理后的副本读取数据、编辑模板。源文件原件始终不修改。
- 可勾选“保留源文件处理结果”：处理副本另存到输出目录，文件名为“原文件名_已编辑.xlsx”；若重名则追加编号，不覆盖现有文件。没有匹配到源工作表的处理规则时，不会另存未处理副本。

## 数据与模板设置

可配置多个目标工作表。每个目标表的源文件列表可以留空，也可以按顺序添加多份源文件；源工作表名留空时使用该源文件第一张表。多份源数据依次追加。复制列范围只在关联了源文件时必填，结束行留空时按所有已使用列寻找首个整行空白边界，否则使用最后非空行。

某目标表有关联源数据时，模板临时副本会清理该表既有数据区，再复制处理后的源数据并填充公式。没有关联源文件时，该表内容保持原样。公式从“粘贴起始行”的上一行读取并填充；只有源数据任务需要公式填充。前映射在模板清理后、主数据复制前执行；后映射在首次完整重算后执行，二者均是模板工作簿内的区域拷贝，源/目标尺寸必须一致。

## 处理范围与工作流

默认工作流先执行**源文件规则处理**，再清理/编辑模板；随后执行前映射、数据复制、公式填充、首次重算、后映射、文本分列/区域筛选/去重/格式转换、最终重算保存，最后输出区域文件和文本预览。工作流页将源文件处理列为必需前置阶段，不能移到模板编辑之后。

每条区域规则可选择“源文件”或“目标工作簿”，并指定工作表和范围。`A1` 表示整张工作表；`D1` 表示整列 D；`A5` 表示第 5 行；整表、整行和整列均按 WPS `UsedRange` 裁剪后执行。区域筛选另支持单填 `A` 表示 A 列，以及小写 `a1` 表示 A1 单格。源文件规则使用 WPS 在临时副本中执行，之后模板读取该副本的处理结果；同名工作表需要至少被一份已配置源文件使用。模板规则直接应用于主结果临时工作簿。

- **区域筛选**：支持等于、不等于、包含、不包含、开头为、结尾为、大于/大于等于/小于/小于等于、为空和不为空；文本匹配不区分大小写，数字条件支持数值比较。可设置表头。`A` 表示整列，`a1` 表示单格，`A1` 表示整张工作表，也可填写 `A1:F100`。筛选只压缩所选区域，不删除整张工作表的物理行；需要保持整条记录对齐时，应将相关列全部包含在区域内。
- **去重**：按区域整行或区域内指定的一列/多列判重，稳定保留第一次出现的记录；有表头时保留首行。只压缩所选区域，不删除工作表物理行。
- **文本分列**：从明确指定的单列按分隔符拆分，逐列设置文本、数字或日期类型和输出起始列；目标区域必须为空，避免覆盖现有数据。整张工作表不适用于文本分列，因为它必须指定唯一输入列。
- **格式转换**：将指定范围转换为文本、数字或日期，并设置相应数字格式。日期支持日期单元格、Excel 日期序号及常见日期文本格式。

源文件侧规则先于模板规则执行。筛选、去重、分列和格式转换都只修改副本；启用“保留源文件处理结果”后，副本才会另存到输出目录。区域处理每项最多处理 500,000 个单元格；目标范围与公式区域冲突时会停止以保护公式。

## 区域 XLSX、PNG 与文本预览

在“区域 XLSX 输出”页添加模板工作表及范围。每个区域 XLSX 保留模板相应单元格的填充色、字体颜色、数字格式/显示位数、边框和对齐等单元格样式。图片复选框只控制是否额外导出 PNG，不影响 XLSX；区域文件输出不会覆盖现有文件。文本预览/复制可配置多个工作表范围；完成保存后界面显示区域内容，并可按行换行、列间 Tab 的方式复制。

## 配置格式

配置版本为 **11**。结果映射字段已移除；区域 XLSX 配置、可选 PNG 开关及可选保留源副本开关均会保存。模板独立编辑时，`jobs[].sources` 可以是空数组，且 `copy_start_col`、`copy_end_col` 均无需填写。示例工作流及规则：

```json
{
  "config_version": 11,
  "workflow": [
    "source_preprocess", "template_cleanup", "pre_mapping", "source_copy",
    "formula_fill", "formula_recalc", "post_mapping", "TextToColumns",
    "RegionFilter", "Deduplicate", "FormatConvert", "final_recalc_save",
    "image_output", "text_output"
  ],
  "retain_edited_sources": false,
  "export_region_pngs": false,
  "jobs": [{
    "template_sheet": "汇总",
    "header_rows": 1,
    "start_row": 2,
    "formula_range": "EB:EN",
    "sources": []
  }],
  "FormatConvert": {
    "enabled": true,
    "rules": [{"scope": "source", "sheet": "明细", "range": "C2:C100", "mode": "number"}]
  },
  "RegionFilter": {
    "enabled": true,
    "rules": [{
      "scope": "target", "sheet": "汇总", "range": "A1:F100",
      "has_header": true, "filter_column": "C", "operator": "greater_equal", "criteria": "10"
    }]
  }
}
```

旧配置会自动迁移；旧结果映射会被移除，但前映射、后映射和区域 XLSX 仍保留。默认配置见 `default_config.json`。

## Windows 构建与验证

main-only 包附带 `install_and_build.bat` 和 Inno Setup 脚本。Windows 上需要 Python 3.10+、WPS 表格和可选的 Inno Setup 6；运行构建脚本后会执行语法检查、自检与静态回归，并生成 PyInstaller 程序目录和 v16 安装器。当前代码已在 Linux 上完成静态及合成工作簿测试；Windows/WPS COM、GUI 与 EXE 仍需在目标 Windows 环境验证。
