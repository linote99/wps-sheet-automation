# WPS 表格多源汇总处理器 v22 主程序源码包

本包包含 v22 / 配置 v17 的主程序源代码、使用说明、默认配置及主程序静态回归测试，适用于 Windows 11 + WPS 表格 + 无宏 XLSX。

## 运行与构建

本包不含预编译 EXE 或安装器。请在装有 WPS 表格的 Windows 11 电脑上解压后运行 `install_and_build.bat`。脚本会创建项目虚拟环境、安装 `requirements.txt` 中的依赖、运行自检和主程序静态回归测试，并仅构建主程序到 `dist\WpsSheetAutomation\WpsSheetAutomation.exe`。首次构建需要网络下载依赖。

构建后可运行 `run_app.bat` 启动源码程序；使用 EXE 时从 `dist\WpsSheetAutomation\WpsSheetAutomation.exe` 启动。

## 主程序包含的功能

- 多源按序合并、按源文件规则预处理，再用处理后的合并结果编辑模板；原始源文件和模板不被覆盖。
- 可选择是否另存合并源工作簿；区域 XLSX 输出保留，PNG 图片输出已移除。
- 公式填充、结果映射与后映射、筛选、文本分列、去重、格式转换及可复用配置。
- 区域筛选范围留空表示整页；`A`/`a` 表示整列，`A1`/`a1` 表示 A1 单元格；工作表留空默认首张表，表名匹配不区分大小写。
- 独立源文件合并可将 CSV 首源与后续 XLSX 合并输出为 XLSX。

## 安全与验证说明

本包是主程序源码，不含预编译 EXE、签发私钥或管理员密钥生成器构建目录。构建脚本只生成主程序，不会复制或生成签发私钥。静态回归目前在 Linux 环境通过；Windows/WPS COM、实际公式重算和 EXE 仍需在目标电脑验收。正式处理重要文件前，请先使用原件副本和少量样例验证配置。
