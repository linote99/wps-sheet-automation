# WPS 表格多源汇总处理器

面向 **Windows 11 + WPS 表格 + 无宏 XLSX** 的 GUI 工具。支持模板处理与独立源文件合并；两种模式均另存新文件，不覆盖模板或原始源文件。

## v17 修订版（配置 v13）

- 新增“公式填充”规则：可以输入自定义公式，或指定同一工作表中的公式单元格作为种子；由 WPS 将公式按相对引用填满所选区域。公式由 WPS 解析和计算，可使用当前 WPS 版本支持的函数；外部工作簿引用及部分外部访问函数仍由既有安全检查拦截。
- 公式填充既可用于源文件，也可用于模板。源侧在 WPS 临时副本中先执行、重算，再读取处理结果；目标侧在模板的输出副本中执行。源文件原件不会被修改。
- 公式填充会替换所选范围内原有的值或公式；可在不同规则间分别指定范围。后续文本分列、筛选、去重、格式转换不能覆盖公式区域，以避免丢失公式。
- 区域规则工作表名留空时使用第一张表，填写名称时不区分大小写。区域筛选范围只有留空时表示整张工作表；`A`/`a` 表示整列 A，`A1`/`a1` 均表示单元格 A1。整表/整行/整列规则按 WPS `UsedRange` 裁剪。
- 恢复可选的“结果映射”：可按每个目标表将公式列已计算结果按值或文本写入指定目标列；不配置时不会强制写回。原有“后映射”独立保留，可复制任意源/目标区域，二者按“结果映射→后映射”顺序执行。
- 区域 XLSX 输出保留；不再提供图片导出。
- 模板可单独处理，无需添加源文件。无源目标表会保留模板已有内容；仍可执行模板范围规则、公式填充、映射、区域输出和文本预览。
- 可按目标子表自定义合并源副本文件名；留空默认为模板子表名。合并副本是否另存到输出目录可选，旧配置中的源副本保留开关会自动迁移。

## 数据与模板设置

可配置多个目标工作表。每个目标表的源文件列表可以留空，也可以按顺序添加多份源文件；源工作表名留空时使用源文件第一张表。源文件先合并到一个临时工作簿，首份源的复制范围首行始终保留，后续每份源可选择保留复制范围首行或将其作为重复表头跳过；后续源默认保留以避免误删。复制列范围只在关联源文件时必填，结束行留空时按所有已使用列寻找首个整行空白边界，否则使用最后非空行。

关联源文件时，程序先合并源文件，再在合并工作簿的安全临时副本中执行匹配到的源规则；命中源规则后，处理结果先另存为输出目录中的独立 `.xlsx` 副本，模板只从该副本读取数据，不会分别读取原始源文件来编辑模板。原件不修改。模板独立处理时，主数据清理、复制和按数据行数自动填充模板公式会跳过；配置的模板规则（包括自定义公式填充）仍可执行。

## 处理范围与工作流

默认工作流先合并源文件，再对合并副本执行源规则并另存处理结果副本，然后模板从该副本取数并清理/编辑；随后执行前映射、数据复制、模板自动公式填充、首次重算、可选结果映射、可选后映射、自定义公式填充、文本分列/区域筛选/去重/格式转换、最终重算保存，最后输出区域 XLSX 和文本预览。工作流页会检查依赖顺序：源合并须先于源规则处理，源规则结果另存后才开始模板编辑；结果映射须在首次重算后、后映射前；自定义公式填充位于后映射之后，并早于其他区域数据操作。结果映射与后映射均可独立留空。

每条区域规则可以选择“源文件”或“目标工作簿”，并指定工作表和范围。通用范围写法（公式填充、文本分列、去重、格式转换等）：`A1` 表示整张工作表，`D1` 表示整列 D，`A5` 表示第 5 行，`B3,B3` 表示单格，两个端点如 `D8,B3` 表示自动规范化的矩形。整表、整行、整列按 WPS `UsedRange` 裁剪；工作表名留空时使用第一张表，名称匹配不区分大小写；区域筛选范围只有留空表示整张工作表；`A`/`a` 表示整列，`A1`/`a1` 均表示 A1 单格。每条处理规则最多处理 500,000 个单元格。

**结果映射**在目标表配置中单独设置：`result_col` 必须位于该表的 `formula_range`，`target_col` 必须在公式范围外；`write_as` 可设为 `value` 或 `text`。它仅将本轮公式结果行写入目标列。**后映射**仍是模板内部任意源/目标区域间的值复制规则，且可不配置；它在首次完整重算及结果映射之后执行。目标表后映射使用整列别名时，只映射从 `jobs[].start_row` 到本轮数据末行的行，不覆盖前一行公式模板；例如 `start_row` 为 3 时，保留第 2 行公式模板。两个功能可同时配置，也可分别留空。

- **公式填充**：模式一填写以 `=` 开头的自定义公式，例如 `=SUM(A1:B1)`；模式二填写同一工作表中的来源单元格（如 `B2`）。程序读取公式的 WPS `FormulaR1C1` 表示，再写入整个选区，让 WPS 按相对引用生成每格公式。公式填充会覆盖选区既有内容；源侧只作用于临时副本，模板侧只作用于结果副本。
- **区域筛选**：支持等于、不等于、包含、不包含、开头为、结尾为、大于/大于等于/小于/小于等于、为空和不为空；文本匹配不区分大小写，数字条件支持数值比较。可设置表头。筛选只压缩所选区域，不删除整张工作表的物理行；需要保持整条记录对齐时，应将相关列全部包含在区域内。
- **去重**：按区域整行或区域内指定的一列/多列判重，稳定保留第一次出现的记录；有表头时保留首行。只压缩所选区域，不删除工作表物理行。
- **文本分列**：从明确指定的单列按分隔符拆分，逐列设置文本、数字或日期类型和输出起始列；目标区域必须为空，避免覆盖现有数据。
- **格式转换**：将指定范围转换为文本、数字或日期，并设置相应数字格式。日期支持日期单元格、Excel 日期序号及常见日期文本格式。

源文件侧规则在合并后、模板编辑前执行；只要有源侧规则命中，处理后的合并副本就会另存到输出目录，文件名为自定义值或对应模板子表名，冲突时自动加编号且不覆盖，模板随后从这个已保存的副本取数。未配置源侧规则时，“保存合并源工作簿”选项控制是否保留合并副本；不保留时仅作为临时输入，整个模板任务结束后清理。区域处理发现其他规则试图覆盖公式区域时会停止并给出提示。

## 独立源文件合并

在“独立源文件合并”区域启用该模式，添加专属的有序源文件列表并设置独立的输出文件名。此模式不要求填写模板，也不会运行模板编辑、源范围规则、WPS 重算、区域 XLSX 导出或其他配置工作流；只把列表中的内容顺序纵向合并到一个名为“合并结果”的工作表，并输出一个新的 `.xlsx` 文件。输出目录仍使用上方的“输出目录”，已存在的结果文件或与任一源文件同路径时会拒绝覆盖。

第一份源文件可以是 `.csv` 或 `.xlsx`；第二份及后续源文件必须是 `.xlsx`。CSV 没有工作表；XLSX 的工作表名可以留空，届时使用第一个工作表。CSV 会检测 UTF-8/UTF-8 BOM 或 GB18030 编码，并尝试检测逗号、分号、Tab 或竖线分隔符；未指定复制结束行时，遇到首个整行空白会停止该源的读取。首份源始终保留复制范围首行；后续源可逐个选择保留或跳过该行，默认保留。合并按单元格值输出，不复制源单元格样式；XLSX 中的公式读取已保存的缓存结果，不会在此模式下重新计算。

## 区域 XLSX 与文本预览

在“区域 XLSX 输出”页添加模板工作表及范围。每个区域 XLSX 保留模板相应单元格的填充色、字体颜色、数字格式/显示位数、边框和对齐等样式；区域文件输出不会覆盖现有文件。文本预览/复制可配置多个工作表范围；完成保存后界面显示区域内容，并可按行换行、列间 Tab 的方式复制。

## 配置格式

配置版本为 **18**。区域处理规则 `sheet` 可留空（默认为对应工作簿第一张表）；指定工作表名时大小写不敏感。区域筛选规则 `range` 可留空（默认为整张工作表）。`jobs[].merged_source_filename` 是模板模式每个目标子表的合并源副本名，可留空（默认为 `jobs[].template_sheet`）；`retain_merged_sources` 控制无源规则时是否保存合并副本，源规则命中时处理结果始终另存。`delete_processed_sources_after_success` 默认 `false`，设为 `true` 时仅在模板任务全部成功后删除本轮另存的源副本；失败时保留副本。旧 `retain_edited_sources` 配置会迁移为 `retain_merged_sources`。`merge_only` 为 `true` 时仍只使用顶层 `merge_sources` 和 `merge_output_filename`，独立合并的输出行为不受此设置影响。

```json
{
  "config_version": 18,
  "merge_only": false,
  "merge_output_filename": "合并结果.xlsx",
  "merge_sources": [],
  "retain_merged_sources": false,
  "delete_processed_sources_after_success": false,
  "workflow": [
    "source_merge", "source_preprocess", "template_cleanup", "pre_mapping", "source_copy",
    "formula_fill", "formula_recalc", "result_mapping", "post_mapping", "CustomFormula",
    "TextToColumns", "RegionFilter", "Deduplicate", "FormatConvert",
    "final_recalc_save", "region_xlsx_output", "text_output"
  ],
  "region_xlsx_outputs": [],
  "CustomFormula": {
    "enabled": true,
    "rules": [{
      "scope": "target", "sheet": "汇总", "range": "C2:C100",
      "formula_mode": "custom", "formula": "=SUM(A2:B2)", "seed_cell": ""
    }]
  }
}
```

独立合并配置示例（其余未列字段由程序默认补齐）：

```json
{
  "config_version": 18,
  "merge_only": true,
  "output_dir": "D:/导出",
  "merge_output_filename": "每日合并.xlsx",
  "merge_sources": [
    {"path": "D:/源文件/首份.csv", "source_sheet": "", "copy_start_row": 1, "copy_end_row": null, "keep_first_row": true},
    {"path": "D:/源文件/后续.xlsx", "source_sheet": "", "copy_start_row": 1, "copy_end_row": null, "keep_first_row": false}
  ],
  "jobs": [],
  "workflow": []
}
```

将 `formula_mode` 设为 `cell` 时，程序从同一工作表的 `seed_cell`（例如 `B2`）读取公式并填充；`formula` 字段此时留空。旧配置会自动迁移。默认配置见 `default_config.json`。

## Windows 构建与验证

此 main-only 源码包附带 `install_and_build.bat` 和 `WpsSheetAutomation.iss`。请在 Windows 安装 Python 3.10+ 与 [Inno Setup 6 或 7](https://jrsoftware.org/isdl.php/Inno-Setup-Downloads)，并确保 `ISCC.exe` 位于默认安装位置或 `PATH`；运行脚本会完成回归、PyInstaller 程序构建和 Inno Setup 编译，生成 `dist\WpsSheetAutomation_Setup_v25.exe`。如果脚本提示找不到 `ISCC.exe`，先安装 Inno Setup 再重试。此普通发布包不含授权签发器或签名私钥；安装后运行软件需要 WPS 表格。当前 Linux 环境已通过 128 项完整回归、116 项发布包回归及 Xvfb 提醒弹窗烟测，Windows 安装器仍须在目标 Windows + WPS 环境验收。
